Machine: 1RB1RF_1LC1LF_0RE1LD_0LB1LD_---1RC_1RA0RD

start: C(2, 1)       [reached from blank tape in 5 steps]

C(z, m) := 0^inf C> (01)^z 1^m 0^inf    (state C on the leftmost 0)

=======================================================================
Proven macro rules (see machine.lean)
=======================================================================

Rule DBL:   C(z, m) -> C(2z, m+2-2z)
            in exactly 6*z^2 micro-steps.
            Requires z >= 2 and m+2 >= 2z.

Rule Init:  blank -> C(2, 1)   in 5 steps.

Rule P123:  C(z, m) -> {D, 1, [false]++ones 4++(zebra(z-2)).reverse,
                           ones(m-2)++zeros p}
            in 2z+9 steps. (Intermediate — not a C-macro state;
            used as a stepping stone inside tm_DBL.)
            Requires z >= 2 and m >= 2.

=======================================================================
Unproven rules (observed only in simulator; no uniform (z,m)->(z',m') formula)
=======================================================================

When the DBL hypothesis m+2 >= 2z FAILS (i.e. m is "too small"),
the next macro transition is irregular. Different (z, m) states with
the same shape can evolve to very different (z', m'). Representative
empirical data from sim6.py running on 5*10^6 base-TM steps:

From (z, 1):
   (2, 1)   -> (2,  4)    in    21 steps   (dz =  0, dm = +3)
   (10, 1)  -> (8,  7)    in   196 steps   (dz = -2, dm = +6)
   (54, 1)  -> (48, 15)   in  5384 steps   (dz = -6, dm = +14)

From (z, 3):
   (8,  3)  -> (10, 1)    in   194 steps   (dz = +2, dm = -2)
   (12, 3)  -> (6, 17)    in   292 steps   (dz = -6, dm = +14)

From (z, 5):
   (14, 5)  -> (4, 27)    in   426 steps   (dz = -10, dm = +22)

etc. No closed form found at the (z, m) level.

=======================================================================
Halting
=======================================================================

Rule Halt:  (none directly observed).
            The only TM-level halting transition is E,0 -> ---.
            At the macro level this would require a zebra-sweep to
            run off the end of the zebra into a right-side 0 — which
            never happens in the DBL regime (the zebra is bounded by
            the ones region). It COULD happen in the irregular regime
            if the bouncer "hits both ends simultaneously", but this
            has not been observed in 10^7 steps.

=======================================================================
Heuristic non-halting argument (user sketch, 2026-04-19)
=======================================================================

The tape length carries a parity which changes whenever the bouncer
hits both ends in the same cycle. Within a parity strip the
"iterated bouncer" starts from the left and roughly doubles each
iteration. Parity flips happen at lengths whose distribution is
1/L-spaced; both parity-flip lengths and doubling lengths grow
exponentially. For the machine to halt, the two exponential
sequences would have to intersect — probabilistically near-zero.
So the machine is "probviously" non-halting (unless it gets
unlucky and halts early).

See sim-results.md for the detailed phase decomposition of the
DBL rule.
