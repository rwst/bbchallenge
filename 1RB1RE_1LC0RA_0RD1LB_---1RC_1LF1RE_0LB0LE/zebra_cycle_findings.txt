## Goal

Find starting state X, step count N, and auxiliary right suffix pattern
such that running N steps from X with zebra(b+1) on left (at some depth)
yields an analogous state with zebra(b) on left, WITH the head position
at the same relative depth and state unchanged.

If found, this gives a simp-provable 'zebra cycle' that closes the
b-induction for pass_shift.
