== Halting conjecture for 1RB1RA_0RC1RC_1LD0LF_0LE1LE_1RA0LB_---0LC ==

Let the macro state be C(a, b, c) := $ 1^{2a+1} C> 0^{2b} 1^c 01 $ (Shawn
Ligocki notation).  The atomic-rule transition function is:

<math display="block">
f(a, b, c) =
\begin{cases}
\mbox{HALT}, & \mbox{for } b = 1 \land c = 0, \\
(1,\ 0,\ 2a+4), & \mbox{for } b = 0 \land c = 0, \\
(1,\ a+1,\ c-1), & \mbox{for } b = 0 \land c \geq 1, \\
(a+2,\ 0,\ 0), & \mbox{for } b = 1 \land c = 1, \\
(a+2,\ 0,\ c-1), & \mbox{for } b = 1 \land c \geq 2, \\
(a+1,\ 1,\ c+1), & \mbox{for } b = 2, \\
(a+3,\ b-2,\ c), & \mbox{for } b \geq 3.
\end{cases}
</math>

<math display="block">
\text{Conjecture: } \neg \exist \, k, \quad f^k(1, 0, 0) = \text{HALT}
</math>

By the Lean theorem <code>tm_halt_iff</code>, this conjecture is <i>exactly
equivalent</i> to the Turing machine not halting from the blank tape.

== Level-2 reduction (a = 1 invariant) ==

Empirically (and provable from f's rules) the orbit enters the a = 1
subset permanently by step 55.  Restricting to a = 1 and composing atomic
steps yields the Level-2 transition function on (b, c):

<math display="block">
g(b, c) =
\begin{cases}
(2,\ 3b+5), & \mbox{for } b \equiv 0 \pmod 2 \land c = 0, \\
(\tfrac{3b+4}{2},\ c-1), & \mbox{for } b \equiv 0 \pmod 2 \land c \geq 1, \\
\mbox{HALT}, & \mbox{for } b \equiv 1 \pmod 2 \land c = 0, \\
(2,\ 3b+6), & \mbox{for } b \equiv 1 \pmod 2 \land c = 1, \\
(\tfrac{3b+5}{2},\ c-2), & \mbox{for } b \equiv 1 \pmod 2 \land c \geq 2.
\end{cases}
</math>

<math display="block">
\text{Conjecture: } \neg \exist \, k, \quad g^k(2, 5) = \text{HALT}
</math>

Starting point (2, 5) corresponds to the first post-transient macro state
C(1, 2, 5), which f reaches from C(1, 0, 0) in 2 steps.

The Level-2 conjecture implies the Level-1 conjecture (and hence the
Turing machine not halting), but not vice versa — it additionally asserts
the a = 1 invariant, which is a separate combinatorial fact that can also
be derived from f.
